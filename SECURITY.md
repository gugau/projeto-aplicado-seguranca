# Política de segurança

## Comunicação responsável

Não abra uma *issue* pública contendo credenciais, chaves, dados pessoais ou instruções completas de exploração. Comunique a vulnerabilidade diretamente ao responsável pelo projeto e inclua apenas as informações necessárias para reproduzir e corrigir o problema.

## Segredos

Este repositório não deve conter arquivos `.env`, chaves SSH, credenciais de nuvem, senhas, certificados privados ou bancos de dados locais. Caso um segredo seja publicado, remova-o do uso imediatamente, revogue ou rotacione a credencial e só depois trate o histórico do repositório.

## Versões suportadas

Por se tratar de um protótipo acadêmico, apenas a versão presente na branch `main` recebe atualizações de segurança.
